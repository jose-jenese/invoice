# Invoice Project

This is a simple invoice management system.

## Features
- Add and edit invoices
- View all invoice records
- Export as PDF (planned)

## Tech Stack
- HTML, CSS, JavaScript
- Node.js (optional)

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
